# Development fixtures

Use a disposable development database. [sample-data.json](sample-data.json) provides request examples and placeholder IDs; replace IDs with those returned by the API.

- fixtures/demo-avatar.png: sample image for user/artist avatars and release/playlist covers.
- fixtures/demo-tone.flac: two-second 440 Hz, 44.1 kHz stereo, 16-bit FLAC with an embedded picture.
- fixtures/demo-mono.flac: one-second, 16 kHz mono, 16-bit FLAC for AAC normalization checks.
- fixtures/create-demo-comment.sql: optional manual comment fixture. Replace USER_ID and SONG_ID, then use the returned comment ID.

Run Register, log in as a configured ADMIN, create a genre, artist and release, then upload a FLAC song. The collection stores IDs automatically. Catalog and playlist requests use these IDs. The main comment workflow creates and deletes its own comments without manual SQL.

Use autoGenerateUser=true and autoGenerateData=true for unique account and media names. Set either false to supply your own values.
