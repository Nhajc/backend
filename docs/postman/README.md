# Nhajc API testing

Import **Nhajc.postman_collection.json** and **Nhajc-local.postman_environment.json**, then select **Nhajc Local**. The collection covers authentication, profile, admin, catalog, playlists, library and comments in one workflow.

## Setup

Start PostgreSQL, MinIO and the backend. Set baseUrl (default http://localhost:8080). Run against a disposable development database: requests create accounts and media, replace avatars, change library state, and delete test playlists/comments. Created artists, genres, releases and songs are retained.

Register creates a USER. To grant ADMIN to a development account, first register it and run this SQL against the intended database:

```sql
UPDATE users SET role = 'ADMIN' WHERE username = 'your_dev_admin';
```

Log in again to obtain an ADMIN access token. Fill adminUsername and adminPassword in the environment. Regular user requests use accessToken; admin requests use adminAccessToken.

## Run

1. Keep autoGenerateUser=true to register a fresh account, or set it false and provide username/email/password. For an existing account, start from Login.
2. Run Auth and User profile. The sample avatar is preselected; replace it with a JPEG/PNG of your choice.
3. Run Admin workflow with an existing ADMIN account. autoGenerateData=true creates unique names. The sample FLAC is preselected in Upload FLAC song. The collection saves resource IDs for subsequent requests.
4. Run Catalog, Playlists, Library and Comments in order. The playlist/comment created for this run are deleted near the end. Optional admin comment deletion runs only when commentId is set.
5. Logout runs last. Negative tests pass when the expected error status is returned.

Library timestamps are nullable ISO-8601 instants. null means the item is not saved/followed/favorited. Search, genres, comments and library use page envelopes. Release songs, playlist songs and artist releases are full arrays. Read every library page before comparing a refreshed snapshot against offline data; absence from one page does not imply removal.

Fixtures and example request data are described in [fake-data.md](fake-data.md). Set Postman working directory to the repository root so fixture paths resolve. Multipart requests contain data (Text with Content-Type application/json) and file (File). Metadata is a JSON object with arrays and booleans. Image files are optional; omitting an image on PUT removes the existing image. Each playlist has its own cover.

## Audio tools

Docker builds flac/fdkaac and a full FDK AAC library with HE-AAC support. For a native Windows run, install flac and fdkaac with HE-AAC support, then add them to PATH or set executable paths in .env:

```dotenv
AUDIO_FLAC_COMMAND=C:/tools/flac/flac.exe
AUDIO_FDKAAC_COMMAND=C:/tools/fdkaac/fdkaac.exe
AUDIO_COMMAND_TIMEOUT_SECONDS=180
```

Use real installation paths without embedded quote characters and restart the backend after changes. Timeout is 1–600 seconds. Verify fdkaac supports profile 5. Audio is streamed from FLAC decoding into AAC encoding; decoded WAV is not written to disk. AAC files place moov before mdat for progressive playback.

## Migration history

V8 consolidates the unreleased V8/V9 work. A database at V7 upgrades normally. A local database that already applied the previous V8/V9 has a different Flyway history: back it up and reconcile schema/history explicitly, or use a fresh disposable database. Do not run Flyway repair alone: it does not apply missing schema changes. Existing duplicate case-insensitive genre names must be resolved before V8 adds their unique index. A full composite comment index on (song_id, parent_id, commented_at DESC, id DESC) covers both song foreign-key lookups and top-level comment paging; the old single-column song_id index is removed.

## CLI

With the backend running and environment values configured:

```powershell
postman collection run docs/postman/Nhajc.postman_collection.json -e docs/postman/Nhajc-local.postman_environment.json
```

Exported environment files contain no real passwords or tokens. Keep filled environments private.
